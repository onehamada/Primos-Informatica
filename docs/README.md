# Primos Informatica

Loja online de produtos de informática.

## 🌐 Site

Acesse nossa loja: https://onehamada.github.io/Primos-Informatica/

## 📋 Descrição

Site de e-commerce desenvolvido com HTML, CSS e JavaScript, featuring:
- Catálogo de produtos
- Sistema de busca
- Carrinho de compras
- Autenticação de usuários
- Design responsivo

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- Service Worker para PWA
- GitHub Pages para hospedagem

## 📦 Deploy

O site é automaticamente implantado no GitHub Pages a cada push para a branch `main`.
